## Chạy lại trên laptop chủ trì (có Docker)

```powershell
scripts/selfhost.ps1 Start                                   # dựng stack thật
node tests/selfhost-network-108.cjs docs/testing/evidence/issue-108-docker.txt
node tests/selfhost-smoke-114.cjs   docs/testing/evidence/issue-114-docker.txt
# #110: bắt đầu từ image bản A đang chạy, script tự build/khởi động bản B giữa chừng
$env:SWITCH_BUILD_CMD = 'docker compose -f compose.selfhost.yaml up -d --build web'; node tests/selfhost-cache-110.cjs docs/testing/evidence/issue-110-docker.txt
scripts/collect-diagnostics.ps1 -SelfTest                    # #115: gói chẩn đoán + kiểm che bí mật
docker compose -f compose.selfhost.yaml stop db; scripts/collect-diagnostics.ps1; docker compose -f compose.selfhost.yaml start db   # #115: tái hiện lỗi DB
```

Các test dùng `MINDSPRINT_BROWSER_URL` (mặc định `http://127.0.0.1:8080`) và `TUTOR_BROWSER` (đường dẫn Chrome nếu chưa cài trình duyệt của Playwright). Mỗi lần chạy tạo một tài khoản thử ngẫu nhiên; mật khẩu không ghi ra tệp.
